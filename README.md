# Apply Specific Modifier Tool for Blender

[English](#english) | [Русский](#русский)

---

## English

A simple and efficient Blender add-on that automatically applies a specific modifier to all selected mesh objects at once. This saves you from having to manually go through every object and click "Apply".

### 🚀 Features
* **Batch processing**: Applies the modifier to all currently selected meshes in one click.
* **Smart filtering**: Safely ignores non-mesh objects (like lights, cameras, or empties).
* **Undo support**: Fully compatible with Blender's history (`Ctrl + Z` works perfectly).

### 🛠️ Installation
1. Download the `Apply_Modifiers.py` file from this repository.
2. Open Blender and go to **Edit > Preferences > Add-ons**.
3. Click **Install...** in the top right corner and select the downloaded `.py` file.
4. Check the box next to **"Apply Specific Modifier"** to activate it.

### 📖 How to use
1. Select all the mesh objects you want to modify in the 3D Viewport.
2. Go to the top menu: **Object > Apply Custom Modifier** (at the bottom of the list).
3. The specific modifier will be instantly applied to all selected objects.

## Русский

Простой и эффективный аддон для Blender, который автоматически применяет конкретный модификатор ко всем выделенным мешам одновременно. Больше не нужно заходить в настройки каждого объекта и нажимать «Apply» вручную.

### 🚀 Возможнойсти
* **Массовая обработка**: Применяет модификатор ко всем выбранным объектам в один клик.
* **Умная фильтрация**: Игнорирует объекты, не являющиеся мешами (лампы, камеры, пустышки).
* **Поддержка отмены**: Полная интеграция с историей Blender (отмена через `Ctrl + Z` работает корректно).

### 🛠️ Установка
1. Скачайте файл `Apply_Modifiers.py` из этого репозитория.
2. Откройте Blender и перейдите в **Edit > Preferences > Add-ons** (Правка > Настройки > Аддоны).
3. Нажмите кнопку **Install...** (Установить) в правом верхнем углу и выберите скачанный `.py` файл.
4. Поставьте галочку напротив аддона **"Apply Specific Modifier"**, чтобы включить его.

### 📖 Как использовать
1. Выделите нужные объекты (меши) в окне 3D Viewport.
2. Перейдите в верхнее меню: **Object > Apply Custom Modifier** (Объект > пункт будет в самом внизу списка).
3. Модификатор мгновенно применится ко всем выбранным объектам.
